# Social Media Comment Sentiment Analyzer

Python-based sentiment analysis project developed as part of an Introduction to Python course.

This project focuses on analyzing social media comments using Python programming concepts, CSV data processing, regular expressions (Regex), data handling libraries, and text analysis workflows.

---

## Project Overview

The Social Media Comment Sentiment Analyzer processes comment datasets from CSV files and analyzes textual sentiment patterns using Python-based logic and preprocessing techniques.

The project demonstrates practical usage of:

- Python functions
- Data processing workflows
- Regex pattern matching
- CSV import/export handling
- Text preprocessing
- Sentiment categorization
